2022 개정 교육과정 고교학점제. 2·3학년 학기마다 과목을 직접 골라 시간표를
미리 짜 보고, 고른 과목이 어느 진로로 이어지는지 함께 봅니다.

- **열기 →** https://created412.github.io/-elective-subject/simulator/
- 파일 하나로 돕니다(`simulator/index.html`). 내려받아 열어도 그대로 작동합니다.

## 학교 자료

전국 **876개교**의 2026학년도 편제표를 학교알리미 공시 자료에서 읽어 넣었습니다.
1학년은 넣지 않습니다 — 공통과목이라 고를 것이 없습니다.

과목이 엉뚱한 학기에 앉는 일이 학생에게 가장 나쁘기 때문에, 편제표를 두 번
따로 읽어 서로 견주는 방식으로 확인했습니다.
