# 과목선택 시뮬레이터

2022 개정 교육과정 고교학점제. 2·3학년 학기마다 과목을 직접 골라 시간표를
미리 짜 보고, 고른 과목이 어느 진로로 이어지는지 함께 봅니다.

- **열기 →** https://yeonsu-pulse.histo5731.workers.dev/games/credit/ (원본 · 늘 최신)
- 사본 → https://created412.github.io/-elective-subject/simulator/
- 파일 하나로 돕니다(`simulator/index.html`). 내려받아 열어도 그대로 작동합니다.

## 학교 자료

전국 **876개교**의 2026학년도 편제표를 학교알리미 공시 자료에서 읽어 넣었습니다.
1학년은 넣지 않습니다 — 공통과목이라 고를 것이 없습니다.

과목이 엉뚱한 학기에 앉는 일이 학생에게 가장 나쁘기 때문에, 편제표를 두 번
따로 읽어 서로 견주는 방식으로 확인했습니다.

## 우리 학교 표가 다르면 직접 고칩니다

공시본이 학교가 실제로 여는 표와 어긋날 때가 있습니다. 공시 뒤에 바꾼 학교도 있고,
공시 파일이 기계로 못 읽히는 모양인 학교도 있습니다.

그래서 **그 학교 선생님이 직접 고쳐 올릴 수 있게** 했습니다.

1. 프로그램 위쪽 **편집** → **학교 편제표 다시 설정** 으로 우리 학교 표를 고칩니다
   (엑셀·한글·PDF 를 그대로 올리거나 표를 붙여넣으면 됩니다)
2. **편집** → **고친 편제표 보내기** 로 보냅니다. 코드도 가입도 필요 없습니다
3. 만든이가 확인한 뒤 반영하면, 그때부터 모두에게 그 표가 보입니다

곧바로 바뀌지는 않습니다 — 편제표가 틀리면 학생이 시간표를 그르치기 때문에 한 번
거릅니다. 보낼 때 한 학기에 같은 과목이 두 번 있는지, 과목 수보다 많이 고르게 되어
있지는 않은지를 자동으로 검사합니다.

공시본은 지워지지 않습니다. 잘못 반영되어도 한 번에 되돌아갑니다.
